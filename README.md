# PERFFORGE: An Effective Performance-Stressing Benchmark for Improving Code Efficiency

PERFFORGE is a collection of performance-stressing tests generated for a subset of AlphaCode's [CodeContest](https://www.science.org/doi/abs/10.1126/science.abq1158) benchmark. PERFORGE was created with the help of [WEDGE](https://github.com/UChiSeclab/wedge), a framework that implements LLM-guided fuzzing to synthesize performance-exercising inputs for a program-under-test. We hope PERFFORGE can serve to evaluate future (AI-driven) approaches for efficient code generation and code optimization. Please check out our NeurIPS'25 [paper](https://openreview.net/forum?id=Qh458ZamHm) for more technical details.

### Repository structure

The `main` branch of this repository has the following directory structure.

```
perfforge
├── problems
|   ├── problemA
|   |   ├── metadata
|   |   |   ├── synthesized_constraints
|   |   |   |   ├── solultion_XYZ
|   |   |   |   ...
|   |   |   └── problem_statement.txt
|   |   |
|   |   ├── solutions
|   |   |   ├── solution_XYZ.cpp
|   |   |   ├── solution_XYZ.cpp
|   |   |    ...
|   |   └── tests
|   |       ├── input
|   |       └── output
|   ├── problemB
|   |   ├── ...  
...
├── case_studies.md
├── README
└── LICENSE
```

For each problem, we release
- `**/problemXYZ/solutions/**` which includes the original CodeContests C/C++ solutions generated by AlphaCode;
- `**/problemXYZ/tests/**` which includes the input tests WEDGE and their corresponding ground-truth outputs;
- `**/problemXYZ/metadata/**` which include the original problem statement and a sample of the performance-characterizing constraints synthesized by WEDGE along with the prompts used, the LLM's response, and the constraint-augmented modified code.

We also include a colledction of 25 case studies (`case_studies.txt`) for some of the most complex performance-characterizing constraints generated by WEDGE.


### NeruIPS'25 Data

We further provide the raw data used to evaluate PERFFORGE against other efficient performance-test generation tools. Please check out the `neurips25-eval` branch in this repository for more details.
